# Žodinėlis

A Lithuanian 5-letter Wordle-style web game built as a multi-stage team project. The project starts with a static web page and progresses into a reusable C module and a C console tool that customizes or generates web files without manual code edits.

## Team & Roles

* **Matas:** Facilitator, Exhibitor
* **Alan:** Builder (Frontend), Designer
* **Ratmir:** Builder (C)
* **Ignas:** Architect, Critic


## Project Stages & Deadlines

* **Stage 1 (Due November 29, 2026):** Static web page with sample content, layout, and styling, initial project/team setup, cumulative team report start, and individual reports from every team member.
* **Stage 2 (Due December 20, 2026):** Reusable C module (`.h` and `.c`) for team use and optional cross-team exchange/adaptation.
* **Stage 3 (Due January 10, 2026):** C console application that takes user input to customize or generate the web page, plus a published version accessible online (such as via the MIF `www` folder).

## Repository Layout

* `web/` — Static web page files (`index.html`, `styles.css`, `app.js`, and generated/sample word or config data)
* `src/` — C source files and reusable `.h`/`.c` module (Stages 2–3)
* `assets/` — Raw and filtered Lithuanian word lists (e.g., 5-letter words)
* `reports/` — Cumulative team report (`report.md`) appended across stages

## Word List Attribution

Lithuanian word list data is sourced from the open-source `iekaton/lithuanian-words-txt` repository (`lithuanian-words-list.txt`, derived from the OpenOffice Lithuanian spell-checking dictionary), included with its corresponding license (`COPYING`).
